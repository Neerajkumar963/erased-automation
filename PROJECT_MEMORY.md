## 1. Project Overview & Rules
This project manages an automated content pipeline for historical videos/shorts (Hidden History, Unsolved Mysteries, Family Tragedies).
- **Tragedy Slot Rule:** The 7:30 PM timeslot on YouTube is **strictly reserved** for "Family Tragedies". If there is no tragedy video scheduled for a given date, that 7:30 PM slot MUST remain completely empty (blank).
- **Zero Overlap:** When generating new figures for Family Tragedies, there must be absolutely zero overlap with figures used in previous parts.
- **HTML Formatting:** The UI templates (`hidden_family_tragedies_part4.html`) use exactly 4 hashtags, double-newlines for paragraphs (`<br><br>`), no emojis in the caption text, and strict matching of Part 3's CSS (diagonal stripes for mock photo, uppercase labels, etc.).
- **5-Second Loop Strategy (Retention Hack):** Even though HTML planners (like `week7_f1_plan.html`) might label the format as "15 sec", the actual generation script (`generate.py`) strictly outputs **5-second videos**. This is a deliberate retention strategy: a short 5-second video loops multiple times while the user reads the text-heavy screen/caption, skyrocketing watch time and algorithm metrics.

Python scripts should ONLY be used for purely mechanical "dumb work" (like merging videos, extracting ZIPs, or rendering final assets).
- **No External APIs in Scripts:** The Python script (`generate.py`) is treated as a "dumb" renderer (using Pillow and FFmpeg). It must **NOT** rely on external APIs like Pollinations, Gemini, or Fal.ai during runtime.
- **Photo Generation (100% Antigravity & Hook-Centric Rule):** 
  - **No Generic Fallbacks:** The free Pollinations API is completely banned for thumbnail generation because it hallucinated and failed to understand complex scenes. 
  - **100% Antigravity:** The AI Assistant (Antigravity) MUST generate 100% of the photos using its own internal `generate_image` tool and provide the local paths to the script.
  - **Hook-Centric Prompts:** Prompts must NOT be generic background vibes (like "a courtroom" or "a music studio"). The prompt MUST explicitly describe the specific dramatic subject or action (the "hook") of the headline. (e.g., If the headline is about a "Trial", show handcuffs or a suspect; if it's about "Missing Autopsy", show a 'TOP SECRET' medical file with ripped pages). The image must visually fulfill the dramatic tension of the headline.
- **Heading Highlights (Minimalism Rule):** The AI Assistant must format the heading manually using a strictly minimalist approach. A maximum of 2 to 3 words should be highlighted in total. One word (or short phrase) should be the Subject/Entity marked as Orange (`[Word](orange)`). One word should be the Action/Impact marked as Red (`[Word](red)`). The rest must remain default.
- **Body Highlights (Semantic + Mathematical Confetti Rule):** Do **NOT** use the Python auto-highlighter. The AI Assistant must manually apply markup based on these strict mathematical rules:
  - **Base Layer:** Orange = Names/Places/Orgs (Entities). Red = Negative Impact/Harms. Black Bold = Numbers/Dates.
  - **Mathematical Color Ratio (1:1):** The AI MUST literally count the number of Orange and Red highlights in the text. They must be perfectly balanced in a 1:1 ratio (e.g., if there are 5 Oranges, there MUST be 4 to 5 Reds). Do not leave a post lopsided (e.g., 5 Oranges and 1 Red). If needed, strategically highlight more 'Action/Impact' words in Red to achieve balance.
  - **Sleek Highlights (No Blocky Bricks):** Never highlight a long chunk of text (e.g., a 5-word organization name). Keep highlights sleek and sharp (MAX 1-3 words per highlight). If a name is long, highlight only its core/identifying words.
  - **Avoid Vertical Color Stacking:** NEVER put the same color on consecutive lines directly under each other (e.g., Orange on line 1, and another Orange on line 2 right below it). Alternate the styles (Orange -> Bold -> Red -> Orange) to create a true scattered "confetti" look, not vertical stripes.
  - **Zero Dead Zones (Character Count Density):** Do not count words to find gaps; count *characters*. There MUST NEVER be a gap of more than ~60 to 80 characters of plain text. If a gap exceeds 60-80 characters, the AI MUST forcefully find key phrases in that zone and add Bold or Color to ensure a premium reading rhythm, even if it splits a long sentence.
